# Журнал групп

Сайт репетитора: кабинет преподавателя (группы, занятия, посещаемость, домашки, статистика)
и личные кабинеты учеников по персональным ссылкам.

## Как это устроено

- `server/server.js` — сервер сайта. Работает на Node.js 22.13+ без внешних библиотек,
  данные хранит в SQLite (`/var/lib/journal/journal.db`), файлы — в `/var/lib/journal/files`.
- `public/teacher.html` — кабинет преподавателя (`/t/`, вход по паролю на `/login`).
- `public/student.html` — кабинет ученика (`/s/<личная ссылка>`).
- `deploy/` — установка на сервер и автообновление.

Код в этом репозитории не содержит данных учеников: всё хранится только на сервере.

## Установка на сервер (Ubuntu 24.04)

В консоли сервера выполнить одну команду:

```
curl -fsSL https://raw.githubusercontent.com/uskova-math/journal-site/main/deploy/install.sh | bash
```

Скрипт поставит Node.js и Caddy, скачает код, спросит пароль преподавателя и домен
(если домена нет — нажать Enter, сайт откроется по IP-адресу).

## Обновления

Сервер каждые 5 минут проверяет этот репозиторий и, если код изменился,
сам обновляется и перезапускает сайт. Данные при этом не трогаются.

## Полезные команды на сервере

| Что сделать | Команда |
|---|---|
| Сменить пароль преподавателя | `bash /opt/journal/deploy/set-password.sh` |
| Обновить сейчас, не дожидаясь 5 минут | `bash /opt/journal/deploy/update.sh` |
| Посмотреть ошибки сайта | `journalctl -u journal -n 50` |
| Подключить домен | ещё раз запустить команду установки и ввести домен |

Каждую ночь в 3:30 делается копия базы в `/var/lib/journal/backups` (хранятся 14 последних).

## Запуск у себя для проверки

```
echo "пароль123" | npm run set-password
npm start            # http://127.0.0.1:3000
```
